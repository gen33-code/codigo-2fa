Qué es la autenticación en dos pasos

La autenticación en dos pasos, o 2FA, pide una segunda prueba de que eres tú, además de la contraseña. Esa prueba suele ser un código de seis dígitos que cambia cada 30 segundos. Así, aunque alguien consiga tu contraseña, todavía le faltaría ese código para entrar.

Código 2FA es una herramienta en el navegador que calcula esos códigos con el estándar TOTP (RFC 6238), el mismo que usan las aplicaciones autenticadoras habituales.

Cómo funciona un código TOTP

Al activar 2FA, el servicio te entrega una clave secreta, a veces dentro de un código QR. El servicio y esta página usan esa misma clave y la hora actual para obtener el mismo número.

El cálculo se hace con HMAC y un contador que avanza cada 30 segundos, o el periodo que indique el servicio. Como el código caduca enseguida, uno que se filtre deja de servir al poco rato.

Esta página no sustituye un lugar seguro para guardar tus claves de respaldo. Conserva esas claves en un gestor de contraseñas cifrado. Si las pierdes, podrías quedarte sin acceso a la cuenta.

Cómo usarlo

  1. Obtén la clave. En el servicio donde quieras activar 2FA, elige la opción de aplicación autenticadora. Copia la clave de configuración (en formato Base32) o guarda el código QR. Algunos sitios también muestran un enlace que empieza por otpauth://.
  2. Pégala o escanea el QR. Escribe o pega la clave o el enlace en el recuadro de arriba. También puedes escanear el QR con la cámara o subir una imagen del código.
  3. Copia el código. Usa el botón Copiar y pega el número en el servicio para terminar el acceso o la activación. El código se renueva solo cuando se acaba la cuenta regresiva.

Compatibilidad

Esta herramienta sigue el estándar RFC 6238, así que funciona con cualquier sitio que acepte autenticadores TOTP habituales. Entre otros:

  • Correo y cuentas de Google, Microsoft o similares
  • Herramientas para desarrollo, como GitHub
  • Redes sociales y mensajería (X, Discord, Meta)
  • Plataformas de juegos, como Steam
  • Bancos, billeteras y casas de cambio que usen TOTP estándar

También admite claves en Base32, enlaces otpauth://totp/ y, si el enlace lo indica, algoritmos SHA-256 o SHA-512, códigos de 8 dígitos y periodos distintos de 30 segundos.

Preguntas frecuentes

¿Es seguro pegar mi clave aquí?

La clave se procesa solo en tu navegador, con la API de criptografía del propio sistema (Web Crypto). No hay un servidor de por medio, no hay que crear una cuenta y la clave no se guarda en el disco ni en la memoria persistente del navegador. Puedes comprobarlo desconectando internet después de cargar la página: el generador sigue funcionando.

Aun así, usa esta herramienta en un equipo de confianza y evita pegar claves en computadores públicos o compartidos.

¿Puedo usarlo sin conexión?

Sí. Cuando la página ya cargó, no necesita red: el cálculo usa el reloj de tu dispositivo y el navegador. Puedes activar el modo avión y seguir generando códigos.

¿Por qué el servicio rechaza el código?

Lo más habitual es que el reloj de tu dispositivo esté desfasado. Los códigos TOTP dependen de la hora exacta; si se atrasa o se adelanta siquiera un minuto, el número no coincide. Activa la sincronización automática de fecha y hora y vuelve a intentarlo.

También revisa que hayas pegado la clave completa y que no corresponda a otra cuenta.

¿Guardan o venden mis datos?

No. No usamos analítica, cookies de seguimiento ni servicios de terceros. Lo único que esta página puede recordar, si tú cambias el tema, es tu preferencia de apariencia clara u oscura. Las claves no se almacenan.

¿Reemplaza a una app autenticadora?

Sirve como alternativa puntual —por ejemplo, si no tienes el teléfono a mano— siempre que conserves la clave de respaldo en un lugar seguro, como un gestor de contraseñas. No es un almacén de cuentas: cada vez que vuelvas, tendrás que volver a ingresar la clave.

Código 2FA es un generador TOTP que funciona por completo en el navegador. No hay seguimiento. El código de este sitio es abierto y se puede alojar en cualquier página estática.
